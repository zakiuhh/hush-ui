Philosophy

Engineered for aesthetics and precision

Tinted Ink Shadows

Shadows are tinted using underlying base pigments rather than flat cold black, eliminating murky grey edges across dark and light surfaces.

Boundary-Safe Springs

Bounces, tooltips, and sliding pill indicators utilize calculated cubic-bezier easing to ensure micro-presses never clip or induce layout reflows.

Zero Framework Lock-in

Authored in semantic CSS variables, zero runtime dependencies, and lightweight ES Modules. Drop into React, Vue, Svelte, or plain static sites.
